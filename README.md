# iPhone 18 Series Community Blog

**Author:** Keanne Kaide D. Roa  
**Course & Year:** 2nd Year ACT  
**GitHub Owner:** keannez  

## Site Description
This is a 3-page student blog website dedicated to the **iPhone 18 Series**. Visitors can read about the latest iPhone 18 lineup, check live tech/Apple updates, and share their own thoughts, reviews, or questions. Other users can view all posts and reply to comments in real time.

## Public APIs Used
1. **Utterances API (`utteranc.es` / GitHub Issues API):** Used for the public posting and commenting system so users can post thoughts and read comments from others using their GitHub accounts.
2. **Hacker News Algolia Public API (`hn.algolia.com/api/v1/search`):** Used to fetch live, real-time tech articles and discussions related to the iPhone 18 series directly onto the homepage.
